Economics of Social Media – YouTube Topics & Concentration

A browser‑only, zero‑cost lab: extract YouTube metadata via public feeds, label topics with local embeddings, and measure concentration (HHI).

What this class is about (and why economists care)

We’ll study how attention is distributed across topics on YouTube. You’ll:

  • Extract data from public YouTube RSS/Atom feeds (no API keys, no scraping of watch pages, ToS‑friendly).
  • Build embeddings (TF‑IDF vectors) to map text into numbers and assign each video a topic.
  • Measure concentration across topics using the Herfindahl–Hirschman Index (HHI) and visualize results.

Why RSS? Browser security (CORS) blocks direct cross‑site reads. We use a free, read‑only CORS relay (https://api.allorigins.win) to fetch the public feed content with proper CORS headers. Nothing is stored server‑side.

# --- Imports --- import re, math, base64 from urllib.parse import quote as url_quote from io import BytesIO import numpy as np import pandas as pd import feedparser import matplotlib.pyplot as plt from pyodide.http import open_url # --- Topics & seed words (edit to match your syllabus) --- TOPICS = [ "Policy & regulation", "Macroeconomy", "Finance & crypto", "Labor & gig economy", "Competition/antitrust", "Platforms & creators", "Misinformation & moderation", "Ads & monetization", "Privacy & data", "Technology & AI", ] SEEDS = { "Policy & regulation": ["policy","regulation","law","bill","compliance","dma","dsa","fcc","ofcom","eu act"], "Macroeconomy": ["inflation","recession","gdp","interest rate","monetary","central bank","macro"], "Finance & crypto": ["stock","crypto","bitcoin","ethereum","finance","trading","markets","portfolio"], "Labor & gig economy": ["labor","jobs","wage","gig","freelance","union","strike","creator job"], "Competition/antitrust": ["antitrust","monopoly","market power","merger","competition","cartel"], "Platforms & creators": ["creator","influencer","subscriber","platform","tiktok","shorts","youtube"], "Misinformation & moderation": ["misinformation","disinformation","moderation","content policy","fact-check"], "Ads & monetization": ["ad","ads","advertising","cpm","rpm","monetization","sponsorship"], "Privacy & data": ["privacy","data","gdpr","tracking","cookie","surveillance","encryption"], "Technology & AI": ["ai","algorithm","machine learning","neural","recommendation","model","tech"], } # --- Utility: pretty print a small DataFrame --- def show_head(df, n=5): try: from pyscript import display display(df.head(n)) except Exception: print(df.head(n).to_string()) # --- Fetch YouTube RSS feed (via read-only CORS relay) --- def fetch_youtube_feed(channel_id: str, limit: int = 50, relay_base: str = "https://api.allorigins.win/raw?url=") -> pd.DataFrame: """ Build the normal YouTube feed URL, then wrap it with a CORS relay for the browser. Returns a DataFrame with (title, link, published, author). """ base = f"https://www.youtube.com/feeds/videos.xml?channel_id={channel_id.strip()}" proxied_url = relay_base + url_quote(base, safe='') xml = open_url(proxied_url).read() # fetch raw XML via CORS-safe proxy feed = feedparser.parse(xml) # parse RSS/Atom into Python dict rows = [] for e in feed.entries[:limit]: rows.append({ "title": e.get("title",""), "link": e.get("link",""), "published": e.get("published",""), "author": e.get("author","") }) return pd.DataFrame(rows) # --- Tokenization --- WORD_RE = re.compile(r"[A-Za-z0-9']+") def tokenize(text: str): return WORD_RE.findall((text or "").lower()) # --- Build TF-IDF (free local embeddings) --- def tfidf_matrix(texts: list[str]): """ Return (X, vocab, idf): X: L2-normalized TF-IDF matrix (n_docs x vocab_size) vocab: dict token -> column index idf: numpy vector (vocab_size,) """ # 1) Tokenize all docs docs_tokens = [tokenize(t) for t in texts] # 2) Build vocabulary from tokens that actually appear vocab = {} for toks in docs_tokens: for tok in set(toks): if tok not in vocab: vocab[tok] = len(vocab) V = len(vocab) N = len(texts) if V == 0 or N == 0: return np.zeros((N,0)), {}, np.zeros((0,)) # 3) Document frequency per token df = np.zeros(V, dtype=np.int32) for toks in docs_tokens: for tok in set(toks): df[vocab[tok]] += 1 # 4) IDF with +1 smoothing idf = np.log((N + 1) / (df + 1)) + 1.0 # 5) Build TF counts then weight by IDF, L2-normalize rows X = np.zeros((N, V), dtype=float) for i, toks in enumerate(docs_tokens): for tok in toks: j = vocab[tok] X[i, j] += 1.0 X *= idf # TF * IDF norms = np.linalg.norm(X, axis=1, keepdims=True) norms[norms == 0] = 1.0 X = X / norms return X, vocab, idf def cosine_sim(A: np.ndarray, B: np.ndarray) -> np.ndarray: """ Cosine similarity between two L2-normalized matrices (n x d) and (m x d) """ if A.shape[1] == 0 or B.shape[1] == 0: return np.zeros((A.shape[0], B.shape[0])) return A @ B.T # --- Topic classifier (topics = nearest topic doc in TF-IDF space) --- def assign_topics_with_tfidf(titles: list[str]) -> list[str]: topic_docs = [t + " " + " ".join(SEEDS.get(t, [])) for t in TOPICS] corpus = topic_docs + titles X, vocab, idf = tfidf_matrix(corpus) T = len(TOPICS) X_topics = X[:T, :] X_docs = X[T:, :] S = cosine_sim(X_docs, X_topics) # (n_docs x T) idx = S.argmax(axis=1) return [TOPICS[i] for i in idx], X_docs, X_topics, vocab # --- HHI (concentration) --- def hhi_from_counts(counts: pd.Series) -> float: total = counts.sum() if total <= 0: return 0.0 shares = counts / total return float(np.sum(shares**2)) # --- Plot helpers (render to base64 for inline ) --- def fig_to_data_url(): buf = BytesIO() plt.tight_layout() plt.savefig(buf, format="png", dpi=120, bbox_inches="tight") plt.close() return "data:image/png;base64," + base64.b64encode(buf.getvalue()).decode() def plot_topic_shares(counts: pd.Series, title="Topic shares (equal weight per video)"): plt.figure() shares = counts / max(1, counts.sum()) plt.bar(range(len(counts.index)), shares.values) plt.xticks(range(len(counts.index)), counts.index, rotation=45, ha="right") plt.ylabel("Share of videos") plt.title(title) return fig_to_data_url() def pca_project(X: np.ndarray, k=2): """Tiny PCA via SVD on centered matrix (for 2D embedding plot).""" if X.size == 0: return np.zeros((X.shape[0], k)) Xc = X - X.mean(axis=0, keepdims=True) U, S, Vt = np.linalg.svd(Xc, full_matrices=False) return Xc @ Vt.T[:, :k] print("✅ Setup complete. Proceed to Module 1.")

Module 2 — Topics via local embeddings (TF‑IDF)

We’ll represent each title as a numeric vector (“embedding”) using TF‑IDF:

  1. Tokenize titles into words.
  2. Build a vocabulary and compute IDF (rare words get higher weight).
  3. For each title, compute TF‑IDF and L2‑normalize the vector.
  4. Create one “topic document” per topic (topic name + seed words), embed those too.
  5. Assign to the nearest topic by cosine similarity.

Why this is “embedding”: Each title is turned into a vector of numbers that capture word importance. Cosine similarity makes titles close to the topic whose seed words and label best match their vocabulary. (Paid options like “LLM embeddings” exist, but TF‑IDF is free, transparent, and perfect for teaching.)
